# 前端实现

## 启动流程

```js
const docs = loadDocuments();      // 读取 /md/ 下所有文档
const tree = buildTree(docs);      // 按目录分组
createSidebar({ tree, onSelect }); // 左侧菜单
createSearch({ docs, onSelect });  // 搜索
createViewer({ onOpenDoc });       // 右侧阅读区
```

然后决定打开哪一篇：**URL → 上次阅读 → 第一篇**。

## 代码高亮

代码块的 HTML 由自定义的 fence 渲染器产出，顶部信息条里带语言名和复制按钮：

```js
md.renderer.rules.fence = (tokens, idx) => {
  const lang = (tokens[idx].info || '').trim().split(/\s+/)[0].toLowerCase();
  const code = tokens[idx].content;
  const body = hljs.highlight(code, { language: lang }).value;
  return '<div class="code-block">' + bar + '<pre>' + body + '</pre></div>';
};
```

复制按钮用事件委托处理，一次绑定管住全文所有代码块。

## 无刷新切换

点击菜单或站内链接时：

1. `findDocument(docs, id)` 找到目标文档
2. 渲染 HTML，替换阅读区内容，播放一次 200ms 的淡入
3. `history.pushState()` 更新地址栏
4. 菜单高亮同步

没有路由库，也没有整页刷新。

## 样式组织

单文件 `src/styles/main.css`，配色统一用 CSS 变量描述：

```css
:root {
  --bg: #ffffff;
  --bg-sidebar: #fafbfc;
  --text: #1f2328;
  --accent: #2f6feb;
  --content-max: 920px;
}
```

正文最大宽度 920px，阅读区不会铺满宽屏。

## 响应式断点

| 断点 | 行为 |
| --- | --- |
| `> 1023px` | 侧栏常驻，内容居中最宽 920px |
| `≤ 1023px` | 侧栏变抽屉，左上角 ☰ 展开 |
| `≤ 640px` | 缩小标题与留白，隐藏品牌文字 |
