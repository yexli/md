# Markdown Wiki 阅读器

把 `/md/` 目录变成一个可以长期使用的个人 Wiki。

**文件即知识库，Markdown 即内容，Wiki 即阅读界面。**

## 它解决什么问题

Markdown 文件放在硬盘里，用编辑器一篇一篇打开效率很低，也很难在文档之间跳转。
这个项目只做一件事：**把 `/md/` 里的所有 Markdown 变成一个网页阅读界面。**

- 新增文档：把 `.md` 文件放进 `/md/`，刷新页面即可
- 组织文档：用子目录分层，左侧菜单自动形成树形结构
- 阅读文档：排版、代码高亮、表格、图片、内部跳转全部开箱可用

## 不是什么

为了避免越做越重，下面这些**刻意没有做**：

| 不做的 | 原因 |
| --- | --- |
| 数据库 | Markdown 文件本身就是数据源 |
| 用户系统 / 登录 / 权限 | 个人阅读器不需要 |
| 后台管理 / 在线编辑器 | 用编辑器改文件更顺手 |
| 独立后端服务 | 前端直接读文件，少一层故障点 |
| 评论、协作、版本管理 | 交给 Git 就好 |

## 技术选择

只用了三个运行时依赖：

1. **markdown-it** — Markdown 解析
2. **highlight.js** — 代码语法高亮
3. **DOMPurify** — HTML 白名单过滤，防止 Markdown 里的脚本被执行

构建工具是 Vite，开发时热更新，构建产物是一份纯静态文件，随便丢到哪个静态托管上都能跑。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开终端里输出的地址，就能看到左侧菜单和右侧正文了。

> 详细用法见 [使用指南](使用指南.md)，实现细节见 [架构设计](开发指南/架构设计.md)。
