# 使用指南

## 新增一篇文档

把 `.md` 或 `.markdown` 文件直接放进 `/md/` 目录：

```text
/md/
├── 项目介绍.md          ← 直接出现在菜单里
└── 开发指南/
    └── 架构设计.md      ← 归入「开发指南」目录
```

刷新页面，菜单自动更新，**不需要改任何代码**。

## 菜单标题怎么来的

优先取正文里的第一个一级标题：

```markdown
# 这是我想要的菜单标题

正文内容……
```

如果文件里没有一级标题，就退回用文件名（去掉扩展名）。

## 子目录

`/md/` 下的目录层级会原样保留在左侧菜单里，目录可以点击折叠，折叠状态会被记住。

## 搜索

顶栏的搜索框同时匹配**文档标题**和**正文**：

- 标题命中的结果排在前面
- 正文命中的结果会带一小段上下文
- 键盘操作：按 `/` 聚焦搜索框，`↑` `↓` 选择，`Enter` 打开，`Esc` 关闭

## 复制

| 位置 | 作用 |
| --- | --- |
| 顶栏「📋 复制全文」 | 复制当前文档的纯文本 |
| 每个代码块右上角「复制」 | 只复制这一段代码 |

## 文档之间互相链接

Markdown 里的相对链接会被识别成站内跳转，点击后**不刷新页面**直接切换：

```markdown
详见 [架构设计](开发指南/架构设计.md)
返回 [项目介绍](../项目介绍.md)
```

外部链接会自动在新标签页打开。

## 图片

相对路径以当前 Markdown 文件所在目录为基准：

```markdown
![架构图](./images/architecture.png)     ← 与文档同级的 images/ 目录
![流程图](../images/flow.png)            ← 上一级的 images/ 目录
```

以 `/` 开头的路径，则以 `/md/` 为基准，例如 `/images/architecture.png`。

## URL 与阅读记忆

当前文档会写进地址栏，可以直接分享或收藏：

```text
http://localhost:5173/?doc=开发指南/架构设计.md
```

打开顺序是：**URL 指定 → 上次阅读的文档 → 第一篇文档**。
浏览器前进、后退按钮都能正常工作。

## 移动端

窄屏下侧栏会收进抽屉，点左上角 ☰ 展开，选中文档后自动收起。
