# 表格测试

## 基础表格

| 名称 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| doc | string | — | 当前文档路径（相对 `/md/`） |
| theme | string | `light` | 主题 |
| sidebar | boolean | `true` | 是否显示侧栏 |

## 对齐方式

| 左对齐 | 居中 | 右对齐 |
| :--- | :---: | ---: |
| 内容 A | 内容 B | 123 |
| 更长的内容 A | 更长的内容 B | 45678 |
| 短 | 中 | 9 |

## 中文内容表格

| 模块 | 文件 | 职责 |
| --- | --- | --- |
| 文档加载 | `src/utils/documentLoader.js` | 扫描 `/md/`、提取标题、生成目录树 |
| 内容渲染 | `src/utils/markdownRenderer.js` | Markdown 转安全 HTML |
| 左侧菜单 | `src/components/sidebar.js` | 目录树与高亮 |
| 搜索 | `src/components/search.js` | 标题与正文匹配 |

## 表格内含格式

| 语法 | 写法 | 效果 |
| --- | --- | --- |
| 加粗 | `**文字**` | **文字** |
| 行内代码 | `\`code\`` | `code` |
| 链接 | `[名字](地址)` | [示例](https://example.com) |
